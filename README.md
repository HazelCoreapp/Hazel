# Hazel

## One Device. Four Worlds.

Hazel is an adaptive Android launcher designed around four different environments.

### Home
A customizable Android launcher for everyday use.

### Desktop
A desktop-style workspace with windows, multitasking, files and desktop controls.

### Forge
A dedicated gaming environment for your Android games and gaming tools.

### Media
A focused environment for watching, listening and entertainment.

### Hazel Fusion
Connect Hazel to a Windows PC with secure pairing, shared clipboard and PC controls.

## Built for Android
Hazel is designed for Android phones and includes adaptive layouts for foldable devices.
